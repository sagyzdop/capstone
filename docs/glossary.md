# Glossary

> **Status:** Draft · **Updated:** 2026-10-04

| Term | Meaning |
| --- | --- |
| Station | The laptop on the vehicle that runs all computation and shows the operator view |
| Moving station | The vehicle carrying laptop, drone and robot; it drives to the site, then stays stationary |
| Drone / UAV | Unmanned aerial vehicle; hovers at one point and streams video |
| Ground robot / UGV | Unmanned ground vehicle sent to verify and communicate with a victim |
| Orchestrator | Station component that decides what the system does next |
| Dropping point | Known location where the robot is released |
| Tagging | Marking a detected victim's location on the map |
| Triage | Sorting victims by urgency and survivability |
| START | Simple Triage And Rapid Treatment: Red (immediate), Yellow (delayed), Green (minor), Black (deceased / expectant) |
| CDR | Call Detail Record: carrier record of network events, including the cell tower used |
| Cell site analysis | Estimating a phone's location from the towers and sectors it used |
