# Ground Robot

> **Status:** Draft · **Updated:** 2026-10-04

## Purpose

A spherical "tumbleweed" rolling robot. It follows the station's path to the tagged victim, verifies the victim's status, and communicates with them. It is built by the **Robotics team**.

## Responsibilities

- [ ] Follow paths / waypoints from the station
- [ ] Capture video and thermal data
- [ ] Two-way audio with the victim
- [ ] Report status to the station
